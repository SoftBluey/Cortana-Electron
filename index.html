Online dictation needs this Windows setting. Open Windows Settings > Privacy > Speech (Privacy & security on Windows 11), or choose Built-in commands below for limited offline recognition.

These settings control what Cortana hears. Spoken replies use the voice selected above. Online dictation accepts natural phrases and needs Windows online speech recognition. Built-in commands recognise a limited set of phrases offline; you can always type a command.
